# 前景网格热交换（2026-10-16）

## 实现与边界

新增 `HeatExchange` 生产模块，iOS 现接入11个C++模块、11个模块头文件和3个ABI头文件。
能力位由2047更新为4095，完整游戏需要的458752仍未开放。无需重新上传Unity归档。

本阶段支持氧气/二氧化碳世界，或水/真空/Unobtanium世界，在前景网格中交换热量。
新路径在每次内部UpdateData的压力计算之前执行，随后将累积温度复制为压力阶段的固定source。
不再限定流体必须接近300K。水仍需在正常液态温度、流动后的允许质量范围内。
水气混合、相变、背墙换热、辐射、其他材料、疾病和不稳定固体保持明确拒绝。

## 原版行为

分析对象为Build U59-744825-V，SimDLL SHA-256：
`031960f120ac1d59fd8e43f6e1a7369111c629b90c24d52186b691dfe2d8a727`。
依据匹配PDB、局部原始指令和独立调用原版DLL的结果。以下是本机工具证据，不是REA运行记录。

| 原版位置 | 行为 |
| --- | --- |
| `0x458D0` 温度任务 | 每格先右、再上；依据固定source温差至少1K、正导热率、无0x10绝热状态决定是否调用交换 |
| `0x36470` UpdateTemperature | 计算绝热比例和双方接触面积；只累积updated温度，不发物质变化事件 |
| `0x35670` precise helper | 双精度计算热量和平衡温度，结果转回float，再以独立float减/加操作写入updated |
| `0x359E0` DoStateTransition | 在任务全部交换之后扫描相变；当前遇需要相变的输入会原子拒绝 |
| `0x45D9D` / `0x460EB` | 交换前和压力前的updated→source复制边界 |

元素wire记录的比热在+12、导热率+16，气/液/固接触面积系数分别在+32/+28/+24。
绝热byte平方乘原版float常量；双方比例均达到1时按原版logf/expf顺序计算几何均值，
否则取较小导热率，再乘双方接触面积的积。没有以平方根或调误差容限替换。

质量乘比热先在float中舍入。之后热量受导热量、冷侧四分之一温差容量和热侧对应容量三者限制。
原版0.2常量实际是double `0.20000000298023224`。结果先夹到平衡温度、转float，再按
`(newTemperature - sourceTemperature) + updatedTemperature`累积，最后夹到[1,10000]。
零质量路径中SSE MIN/MAX遇NaN选择第二操作数的行为也予以保留。
