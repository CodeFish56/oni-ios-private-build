# 正时间模拟：受限 O2/CO2 混合气体

## 本轮实现与边界（2026-10-16）

`SimCore.NewGameFrame` 依次运行已还原的压力、异种气体压力位移和气体后处理，
按原版单精度调度保留余时、随机种子、压力遍历方向与位移方向。
输出经 `PrepareGameData` 和 `BeginSave` 返回。能力从127增加到511；
世界稳定、完整游戏模拟与完整游戏渲染所需的458752三个能力位仍全部关闭。

当前要求：

- InitializeFromCells 提供确定种子；v15存档不含该种子，Load后正时间仍拒绝。
- Oxygen、CarbonDioxide 与空真空；无内部固体、液体、疾病和位置属性。
- 气体温度处于300K上下0.25K以内，真空不导热、边框具隔热状态。
  这利用原版小于1K温差跳过热交换的分支，尚未实现一般传热与相变。
  压力后的气体若进入相变范围则整帧失败，不冒充处理成功。
- 辐射关闭、背墙为空，每帧最多100次内部更新。
- 每正时间帧后消费PrepareGameData；不声明兼容原版异步积压批次。

计算在临时网格、随机状态和消息上执行，成功才提交。七种未实现输入明确拒绝，
保存及随机状态保持不变。持久稳定计时器和疾病infestation/error数组尚未实现；
单细胞探针不将这些字段计为候选实现的验收范围。

## 与原版一致的规则

异种气体的普通压力交换先跳过；随后使用固定的压力前source，按原版顺序
向下、负遍历方向、正遍历方向、向上尝试压力位移。先将邻格全部内容推到
第二格，再将当前格最多source质量的1/8移入邻格；质量、温度与事件顺序取自
原版指令。四种推移都写flow.w/z，包括水平推移，没有按直觉改成别的分量。

原版第二遍历还存在不对称的边界：x下限max(minX+1,3)，y下限
min(minY+1,3)。分块混合案例核对了这一行为，未擅自统一成对称裁剪。

低质量处理使用原版float32阈值：mass<1e-9无条件清空；mass<.001时，
任一四邻气体质量>=1才清空。清空本格四方向flow与元素/质量/温度/疾病，
保留位置属性。**清空后继续用进入时的气体记录运行密度和随机换位**，
所以邻格气体仍可能被搬回当前格；没有提前continue。

原版蒸发直接删除少量质量，并不补给邻格。测试核对原版最终质量，未强行
加入守恒修正。密度同种气体温度换位不通知，随机换位通知两格。
ChangeSubstance还可能记录Vacuum→Vacuum，不能仅比较元素差异生成事件。
最终通知按格排序去重，旧/新元素来自前后游戏快照。

同帧多次内部更新累积flow，后处理蒸发只清当前格。流量纹理比较压力/位移
后的source元素与最终元素，再计算 `(flow.x-flow.y,flow.w-flow.z)/max(mass,1)`；
元素不符时比例为0。当前气体范围的accumulatedFlow为0，和原版结果一致。
