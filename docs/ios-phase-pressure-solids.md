## 接入的行为

| 系统 | 已接入内容 | 保留的原版细节 |
| --- | --- | --- |
| 全格相变 | Water / Steam / Ice 的冻结、沸腾、冷凝、融化 | 完成所有传热配对后再逐格转换；阈值 ±3 K、转换温度偏移 ±1.5 K、严格比较及 float 运算顺序 |
| 冻结产物 | 已可见的低质量水冻结产生可拾取 Ice；不可见时按原版转为冰格 | 用 `mass/defaultMass` 与 `.8f` 比较；可见性来自上一轮 PrepareGameData；事件保留实际质量和温度 |
| 压力破坏 | 水超压检查一至两层墙体，发 WorldDamageInfo | 下、左、右、上顺序，首个成功即结束；阻力、质量缩放、强度字节、下游液体压力、严格大于比较；不擅自删除墙格 |
| 松散固体 | headless 垂直下落、对角分裂和流体位移 | 共享 RNG、稳定计时器递减、即时 OR31、重复通知、单次调用一直落到支撑点 |
| 保存选项 | `SetSavedOptions` 消息 `1154135737` 与 v15 选项字节 | 先清位再置位；默认 0 为基本下落，位 0 开启对角落沙；未知位拒绝 |
| 游戏输出 | SolidInfo、SolidSubstanceChangeInfo、WorldDamageInfo、SpawnOreInfo | 固体掩码为 -1/0；伤害与产物保留原顺序、重复及生命周期 |

水与下方同种水混温成功时，原版立即结束当前格后处理；不会继续执行压力破坏或部分相变。完整帧包含了这一组合回归。

## 首轮限制的后续处理

- 非平凡部分热转换和 Ice→Water 部分熔化已在已核对域接入；其他目标仍有明确限制。
- 副产物与其他全格材料转换已扩展；后续其他液体流动、升华、疾病、辐射与背墙传热仍未完成。
- **更正：此前三倍 maxMass 的压力置换门槛是误读。原版严格门槛为 1.5 倍，现已实现并补齐临界与组合测试。**
- 非 headless 的落沙对象事件及大地图内存/性能尚未验收；集成后处理已改为一次验证、使用外层事务，消除逐格全图复制。

首轮的 14 模块 /能力 `65535` 已由上述新阶段扩展；7 个 wrapper 不变，完整游戏要求 `458752` 仍未满足，**不能进入可玩殖民地**。500 步世界稳定、持续游戏消息、AOT 回调以及 ARM64/真机验证仍需后续完成。未触发 Actions、签名或安装。
