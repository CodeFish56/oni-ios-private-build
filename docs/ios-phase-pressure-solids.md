# 相变、压力破坏与固体：当前已验证范围

更新日期：2026-10-19。目标为原版 **U59-744825-V**，原始 Windows DLL SHA-256：
`031960f120ac1d59fd8e43f6e1a7369111c629b90c24d52186b691dfe2d8a727`。

## 接入的行为

| 系统 | 已接入内容 | 保留的原版细节 |
| --- | --- | --- |
| 全格相变 | Water / Steam / Ice 的冻结、沸腾、冷凝、融化 | 完成所有传热配对后再逐格转换；阈值 ±3 K、转换温度偏移 ±1.5 K、严格比较及 float 运算顺序 |
| 冻结产物 | 已可见的低质量水冻结产生可拾取 Ice；不可见时按原版转为冰格 | 用 `mass/defaultMass` 与 `.8f` 比较；可见性来自上一轮 PrepareGameData；事件保留实际质量和温度 |
| 压力破坏 | 水超压检查一至两层墙体，发 WorldDamageInfo | 下、左、右、上顺序，首个成功即结束；阻力、质量缩放、强度字节、下游液体压力、严格大于比较；不擅自删除墙格 |
| 松散固体 | headless 垂直下落、对角分裂和流体位移 | 共享 RNG、稳定计时器递减、即时 OR31、重复通知、单次调用一直落到支撑点 |
| 保存选项 | `SetSavedOptions` 消息 `1154135737` 与 v15 选项字节 | 先清位再置位；默认 0 为基本下落，位 0 开启对角落沙；未知位拒绝 |
| 游戏输出 | SolidInfo、SolidSubstanceChangeInfo、WorldDamageInfo、SpawnOreInfo | 固体掩码为 -1/0；伤害与产物保留原顺序、重复及生命周期 |

水与下方同种水混温成功时，原版立即结束当前格后处理；不会继续执行压力破坏或部分相变。完整帧包含了这一组合回归。

## 原版对照

全部使用用户持有的匹配 DLL，在独立进程执行；未运行游戏界面、未改原始 DLL。每组直接探针检查实际 `headless=1 / radiation=0`。

| 验证 | 原版案例 | 比较范围 |
| --- | ---: | --- |
| 相变模块 | 164 | 112 个全格转换（含可见/不可见冻结）；46 个部分相变早退；6 个需要更深路径的输入保持拒绝 |
| 压力模块 | 456 | 原版返回值和 316 条伤害事件逐字节；源/输出网格、计时器、flow、RNG 不变 |
| 固体模块 | 191 | 353 次实际调用，包括 18 组连续 10 次序列；检查下落前倒计时、实际移动、位移与事件顺序 |
| 新增完整帧 | 21 个世界 / 161 帧 | 18 数组、29 事件计数、6 种事件流、保存字节、seed/方向/tick、计时器低五位 |
| 失败回滚 | 4 种新增边界 | 不支持的部分相变、液体压力置换和其他材料相变失败时，网格/RNG/tick/timers/events 不提交 |

普通编译及 ASan/UBSan 均通过。连同旧回归，累计 **65 个世界 / 384 帧**，另有 11 组初始化/Load 和 65537 次真实更新的 tick 回绕检查。

原版 SpawnOreInfo 的字节 7 是未初始化 padding。探针对它单独归零；比较其余全部有效字段。不能将此称为原始 20 字节不加区分的全字节一致。

验证记录：[phase-pressure-solid-verification.json](phase-pressure-solid-verification.json)。源码和工具均由逐文件 SHA-256 绑定；原始游戏表、采集与手机数据不入仓库。

## 仍未实现

- 非平凡的部分液体热转换、热气体对邻格的部分熔化。只在已核对的原版早退条件下放行，其他情况明确拒绝。
- 相变副矿、Water/Steam/Ice 以外的全格转换、其他液体、升华、疾病、辐射与背墙传热。
- 水质量超过三倍 maxMass 的后续压力置换；若更早的密度或破坏分支结束当前格，则按原版保留该结果。
- 非 headless 的落沙对象事件。完整帧材料域为 O2/CO2/Steam、Water、Vacuum、Unobtanium/Ice/Sand/Dirt/SandStone/Granite/Obsidian，并继续受上述边界限制。
- 大地图性能尚未验收。当前不稳定固体直接入口为保证失败原子性，逐次验证并复制网格，需要进一步提供预验证上下文以避免密集沙图的平方级开销。

14 个生产 C++ 模块已加入 UnityFramework；7 个 wrapper 不变，完整游戏要求 `458752` 仍未满足。能力 `65535` 只表示已验证的受限模块，**不能进入可玩殖民地**。500 步世界稳定、持续游戏消息、AOT 回调以及 ARM64/真机验证仍需后续完成。本轮未触发 Actions、签名或安装。
